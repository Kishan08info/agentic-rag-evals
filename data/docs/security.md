# Nimbus Analytics — Security & Compliance

## Certifications

Nimbus Analytics is **SOC 2 Type II** certified, with the audit renewed annually.
GDPR and CCPA data-processing agreements are available on all paid plans.

## Encryption

- Data is encrypted at rest with **AES-256**.
- Data in transit is protected with **TLS 1.3**.
- API keys are stored as salted hashes; raw keys are shown only once at creation.

## Access control

- **SSO/SAML** single sign-on is available on Scale plans and above, with Google
  Workspace and Okta supported out of the box.
- Role-based access control separates Admin, Analyst, and Viewer roles.
- Audit logs record every dashboard change and data export for 12 months.

## Data retention and residency

- Default data retention is **13 months** on paid plans (30 days on Starter).
- Enterprise customers can choose **EU data residency**, pinning storage and
  processing to Frankfurt, Germany.
- Backups are encrypted and retained for 35 days, then securely destroyed.
